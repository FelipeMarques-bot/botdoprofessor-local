Perguntas frequentes

Preciso saber programar para usar?

Não. O BotDoProfessor é um software pronto para usar. Você baixa, instala e funciona como um assistente: preenche os dados e clica em "Lançar". Nenhuma configuração técnica necessária.

Funciona no meu SGE?

O BotDoProfessor foi desenvolvido para o SGE 8147 e suporta portais personalizados via configuração. Se você usa o SGE, provavelmente funciona. Em caso de dúvida, entre em contato antes de comprar.

Como preparo as notas para lançar?

Você tem quatro opções: (1) Conecte o Notion e o programa puxa as notas automaticamente, (2) crie uma planilha Excel ou CSV com colunas "Aluno" e "Nota", (3) cole o link de uma Google Sheets, ou (4) tire uma foto da lista de notas (caderno, quadro, planilha impressa) e o programa extrai automaticamente usando inteligência artificial.

Meus dados estão seguros?

Sim. Suas credenciais (CPF) ficam criptografadas no seu computador. Nenhum dado é enviado para servidores externos. O pagamento é processado pelo Mercado Pago, que é uma plataforma segura e certificada.

Como funciona o pagamento?

Você escolhe o plano, preenche seus dados e paga via Pix ou cartão de crédito pelo Mercado Pago. Assim que o pagamento é confirmado (instantâneo no cartão, até 5 min no Pix), a chave de licença é enviada para seu email automaticamente.

E se eu não gostar?

7 dias de garantia. Se não gostar do programa, entre em contato e processemos a devolução do valor pago.

Preciso de internet para usar?

Sim, na primeira vez (para validar a licença e acessar o SGE). Após o login, o programa funciona com o navegador aberto, então a conexão deve permanecer ativa durante o lançamento.
